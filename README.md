# Wizard Punkte – neue Version

PWA für die Wizard-Punkteabrechnung.

## Änderungen
- moderne, mobilfreundliche Oberfläche
- Ansage- und Stichfelder sind beim Start **leer** statt mit 0 vorbelegt
- automatische Vorschau der Punkte
- 3–6 Spieler und normale Wizard-Wertung
- Spielstand lokal auf dem Gerät
- letzte Runde zurücknehmen
- PWA-Installation auf unterstützten Browsern

## GitHub Pages
Alle Dateien des Ordners in das bestehende Repository `wizard-punkte` hochladen und Änderungen committen. Die bestehende GitHub-Pages-Adresse bleibt gleich.
